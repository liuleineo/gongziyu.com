配置豆包 Seedream API Key

本工具使用火山引擎「豆包 Seedream」大模型生成图片，首次使用需要配置 API Key。

  1. 前往 火山引擎方舟控制台（console.volcengine.com/ark）
  2. 开通「豆包·Seedream」图像生成模型服务
  3. 创建 API Key（推理接入点），复制形如 ark-xxxx 的 Key
  4. 将 Key 粘贴到下方输入框并保存
Key 仅保存在本机浏览器 localStorage，不会上传到任何服务器。
