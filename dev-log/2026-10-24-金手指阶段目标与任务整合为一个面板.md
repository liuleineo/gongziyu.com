# 2026-10-24 金手指：阶段目标与任务清单整合为一个面板

## 需求
把「阶段目标」和「任务清单」两张卡合并成一个面板，按阶段逐段展示：阶段信息 → 阶段进度条 → 该阶段任务。

## 改动

### `goal.php`
删掉原来的「阶段目标」「任务清单」两个 section，合并为一张卡：
```html
<section class="plan-card">
  <h3>阶段目标与任务<span class="plan-card-note">按阶段推进，完成上一阶段再进入下一阶段</span></h3>
  <div id="stageTasks"></div>
</section>
```
卡片顺序调整为：每日日常任务 → 阶段目标与任务（日常在最前，手机端不用穿过长列表才能打卡）。

### `assets/goal.js`
- 抽出 `taskItemHtml(task, isDone)`（任务项 markup 复用）。
- 新增 `renderStageTasks(plan, done)`：按 `plan.goals` 顺序渲染每个 `.goal-node.stage-block`，块内依次是
  - 阶段头：序号圆点 + 阶段徽章 + 阶段目标 + 说明 / 衡量标准 / 节点 + 状态徽章 + 百分比
  - 阶段进度条
  - `阶段任务 x/y` + 该阶段任务列表（复用 `.task-item`）
- 删除 `renderGoals()` / `renderTasks()`；调用点（`renderAll()`、`finishTask()`、「清空进度」）统一改为 `renderStageTasks()`。
- 任务勾选事件从 `el.taskGroups` 改挂到 `el.stageTasks`；`el.goalList` / `el.taskGroups` 引用移除，新增 `el.stageTasks`。
- `updateProgress()` 的分组计数改为按阶段算 `x/y` 并写入 `gc-{i}`（不再依赖 DOM 遍历）。

### `assets/goal.css`
- 新增 `.stage-block .task-stage { margin-top: var(--space-4); }`、`.stage-block .task-item { background: var(--bg-primary); }`（任务项与阶段块底色区分开）。

### `sw.js`
- 缓存版本 `v17 → v18`。

## 验证（真实接口，「每天读书30页并减脂5斤」5 阶段 15 任务）
- 面板结构：5 个阶段块，每块含阶段头 + 进度条 +「阶段任务 0/3」+ 3 个任务项，状态徽章 进行中 / 待解锁 正确。
- 勾完第1阶段 3 个任务 → 第1阶段「已完成 / 100% / 3/3」，第2阶段转「进行中」，总进度 20%，并弹出该阶段大奖励「买一本想读很久的书 / 完成第1阶段·启动」；刷新后保持。
- PC 1440：两列，每日日常任务 x=24、阶段目标与任务 x=730，各 686px。
- 手机 390：两卡单列（日常在前），无横向溢出，无控制台报错。
