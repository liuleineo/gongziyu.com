# 2026-10-22 金手指：每完成一个任务给小奖励，完成阶段给大奖励

## 需求
每次完成任务都给小奖励；完成阶段目标给大奖励。

## 设计
- **小奖励**：内置即时奖励池（8 条，如"喝一杯水，顺便远眺 20 秒""听一首喜欢的歌"），随机发放且不连续重复；一次性、不入库。
- **大奖励**：与阶段一一对应。`plan.rewards[i]` 即第 `i+1` 阶段的大奖励；方案奖励不足时用内置大奖励兜底池（6 条，如"吃一顿一直想吃的大餐""给自己放半天假"）。
- 奖励卡复用同一个弹窗组件，用 `is-big` / `is-small` 区分样式与文案，一次可排队弹多个（例如一个任务同时收官多个阶段，实际按阶段顺序依次弹）。

## 改动

### `assets/goal.js`
- 新增 `SMALL_REWARDS` / `BIG_REWARDS` 常量池、`pickSmallReward()`（避免与上一条重复）、`stageNameOf()`、`bigRewardFor(plan, i)`。
- 新增 `finishTask(id)`：勾选任务 → 保存 → 对比前后阶段状态 → 返回 `{ plan, newStages }`；**弹窗与列表勾选共用这一条路径**，所以在任务清单里直接打勾也会发奖励。取消勾选不触发。
- 新增 `grantRewards(res)`：有新完成阶段 → 入队对应大奖励；否则入队一条随机小奖励 → `showRewardQueue()`。
- `completeReminderTask()` 简化为 `finishTask()` + `closeReminder()` + `grantRewards()`。
- `showRewardQueue()` 支持两种形态：大奖励（橙色、kicker「大奖励已解锁」、按钮「收下奖励」、条件为"完成第N阶段·阶段名"）／小奖励（绿色、kicker「小奖励到账」、按钮「收下，继续」）。
- 播报：小奖励 `宿主，小奖励到账，{奖励}。`；大奖励 `恭喜宿主，完成第N阶段·阶段名，大奖励解锁：{奖励}。`
- 奖励清单解锁规则改为按阶段：前 N 条奖励由对应阶段完成解锁，状态文案显示"完成第N阶段"；超出阶段数量的奖励仍按 `unlockAt` 百分比解锁。统计"已解锁奖励"同步为该口径。
- 删除已无引用的 `planProgress()`。

### `goal.php`
- 奖励弹窗 kicker 加 `id="rewardKicker"`（用于切换文案）。
- 奖励清单标题加说明："每个任务有小奖励，完成一个阶段解锁对应大奖励"。

### `assets/goal.css`
- 新增 `.reward-modal.is-small`：绿色描边/投影、绿色 kicker、44px 小图标；大奖励保持橙色。

### `sw.js`
- 缓存版本 `v14 → v15`。

## 验证（假接口：4 阶段 / 10 任务 / 3 条方案奖励）
- 任务 1、2：弹小奖励（随机且不重复），清单仍显示"完成第1阶段"，已解锁 0。
- 任务 3（第1阶段收官）：弹**大奖励**「一杯咖啡 / 完成第1阶段·启动」，清单第1条变"已解锁"，统计 1。
- 任务 8（第3阶段收官）：大奖励「一次旅行 / 完成第3阶段·优化」，统计 3。
- 任务 10（第4阶段收官，方案奖励只有 3 条）：走兜底池「做一次按摩或 SPA / 完成第4阶段·验收」。
- 取消勾选：不弹任何奖励；重新勾选：正常再发奖励。
- 播报文案正确，无控制台报错。
