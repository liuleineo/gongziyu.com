# 2026-10-22 金手指：PC 端阶段目标 / 任务清单 / 奖励清单 三列并排

## 需求
手机端保持单列（现状不变），PC 端把"阶段目标、任务清单、奖励清单"一排展示。

## 改动

### `assets/goal.css`
新增 `@media (min-width: 1024px)` 块：
- `.goal-plan`：`max-width` 720px → 1440px，改为 `display: grid; grid-template-columns: repeat(3, minmax(0, 1fr)); gap: var(--space-5); align-items: start`，三张卡并排。
- 卡片：`margin-bottom: 0`，`max-height: calc(100vh - 180px)` + `overflow-y: auto` + `overscroll-behavior: contain`，每列独立滚动，避免长任务列表把页面拉得过长。
- 列内滚动时标题吸顶：`h3` 改 `position: sticky` 并用负 margin/padding（`calc(-1 * var(--space-6))`）铺满卡片宽度，背景 `var(--bg-tertiary)`，`z-index: 2`。
- 细滚动条样式（6px，`::-webkit-scrollbar-thumb` 用 `--border-light`）。

### `sw.js`
- 缓存版本 `v7 → v8`（goal.css 已更新）。

- 视口 1440 / 1280：`grid-template-columns` 为 3 等分（1280 下每列 397px），三张卡 `y` 均为 1138（同一行并排），无横向溢出。
- 列内滚动：任务列 `scrollTop = 200` 时，`h3` 顶部与卡片顶部差 1px（标题吸顶生效）。
