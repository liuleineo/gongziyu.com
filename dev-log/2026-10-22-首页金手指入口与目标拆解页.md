# 2026-10-22 首页 Hero 改为金手指入口 + 新增目标拆解页

## 需求
把首页 Hero 区域改成「金手指」入口：用户输入目标 → 点击"实现目标" → 进入金手指页面；
该页面用 DeepSeek AI 拆解目标（资源 / 长期目标 / 短期目标 / 任务清单），用户完成一项勾选一项，实时显示完成进度；
DeepSeek 的 Key 配置在服务器，不下发到浏览器。

## 关键实现
- **Key 只在服务端**：读取优先级为 环境变量 `DEEPSEEK_API_KEY` → `$_SERVER['DEEPSEEK_API_KEY']` → `api/config.local.php`。前端永远拿不到 Key。
- **接口防护**：同源校验（Origin 与 Host 比对，忽略端口）、目标长度截断（300 字）、按 IP 限流（40 次/小时，文件锁计数）、相同目标方案缓存 6 小时（系统临时目录）。
- **AI 输出规整**：`response_format: json_object` + 去代码围栏/截取 `{}` 兜底解析 + `goal_normalize_plan()` 统一字段、校验下标越界、任务为空时兜底生成。
- **错误映射**：401/402/403/422/429/5xx 转中文提示；未配置 Key 返回 `code=no_key`，前端提供「使用示例方案」降级。
- **进度**：任务按 `stage` 分组，勾选写入 localStorage（按目标 hash 分别存储，支持多目标切换、删除、清空进度、重新拆解时按标题保留已勾选项）；总进度环 + 短期目标进度条 + 长期目标进度条（由 shortTermIndex → longTermIndex 聚合）。

## 服务端配置方式（部署时）
1. 推荐：服务器环境变量 `DEEPSEEK_API_KEY`（Apache `SetEnv` / php-fpm `env[DEEPSEEK_API_KEY]=...`）；
2. 或：`cp api/config.local.php.example api/config.local.php` 并填入 Key；
3. 访问 `/api/goal.php?action=status`，返回 `{"configured":true}` 即配置成功。
