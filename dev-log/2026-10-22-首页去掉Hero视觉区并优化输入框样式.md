# 2026-10-22 首页去掉 Hero 右侧视觉区并优化输入框样式

## 需求
去掉 `index.php` Hero 右侧的 `.hero-visual`（粒子 + AI 大脑 SVG），并检查输入框样式。

## 改动
文件：`index.php`
- 删除 `.hero-visual` 整块（粒子、ai-brain SVG 及其渐变 defs），Hero 只保留左侧内容区。

文件：`assets/styles.css`
- `.hero .container`：`grid-template-columns: 1fr 1fr` → `1fr`，并补 `width: 100%; min-width: 0`
  （原因：`.hero` 是 flex 容器，`.container` 作为 flex item 会收缩成 fit-content，实测只有 690px 宽，补 width 后才占满）
- `.hero-content`：新增 `max-width: 860px; margin: 0 auto; text-align: center`
- `.hero-goal-box`：背景 `var(--bg-tertiary)` → `var(--bg-primary)`，圆角 `xl` → `2xl`，新增轻投影 `0 8px 24px rgba(15,23,42,.06)`
- 新增 `.hero-goal-box:focus-within .hero-goal-icon { color: var(--primary); }`，图标加过渡
- `.hero-goal-input`：内边距 `var(--space-1)` → `var(--space-2)`
- `.hero-goal-btn`：圆角 `var(--radius-xl)`
- `.hero-goal-hints` / `.hero-actions-sub`：加 `justify-content: center` 与新布局对齐

## 效果
- 桌面 1280：Hero 容器占满，内容区 860px 居中（左右各 210px），输入框 634px + 按钮 158×58，整框高 76px
- 移动端 390：输入框与按钮自动纵向排列，按钮占满宽度
- 跳转链路不变：输入目标点"实现目标" → `/goal.php?goal=...`

## 备注
- `styles.css` 中的 `.hero-visual` / `.ai-particles` / `.particle*` / `.ai-brain` 样式暂保留未删（已无引用，无副作用）；`assets/script.js` 里的粒子鼠标视差代码查询 `.particle` 得到空集合，不会报错。如确认不再复用可后续清理。
