# 2026-10-22 金手指：阶段改为横向坐标轴展示 + 进度条显示当前阶段

## 需求
把"当前阶段"文字改为横向坐标轴：一行展示所有阶段，背景以进度条方式显示当前阶段。

## 改动

### `goal.php`
原 `<p class="plan-current" id="planStage">` 换成横轴结构：
```html
<div class="stage-axis" id="planStage" hidden>
  <div class="stage-axis-line" id="stageAxisLine">
    <span class="stage-axis-fill" id="stageAxisFill"></span>
  </div>
  <div class="stage-axis-nodes" id="stageAxisNodes"></div>
</div>
```
- `.stage-axis-line` 是轨道（灰色横线），`#stageAxisFill` 是渐变填充进度条；
- `.stage-axis-nodes` 里每个阶段一个节点：圆点（序号）+ 阶段名。

### `assets/goal.js`
- 新增 `renderStageAxis(plan)`：为每个阶段生成 `.stage-node`（`sn-i`），并把轨道左右各内缩 `100/(2N)%`，使轨道两端正好落在首/末圆点圆心。
- 阶段名取 `stage` 中 `·` 之后的部分（"第1阶段·启动" → "启动"），完整信息放在 `title` 提示里（`阶段 · 目标`）。
- `updateProgress()`：节点同步 `is-done` / `is-current` / `is-locked` 三态；填充宽度 = `(当前阶段下标 + 该阶段完成百分比/100) / (阶段数 - 1) × 100`，即进度条填充到当前阶段节点并随阶段内部进度继续推进；全部阶段完成时填充 100%。

### `assets/goal.css`
- 新增 `.stage-axis*` / `.stage-node` / `.stage-dot` / `.stage-name` 样式：圆点未解锁为灰描边，已完成与进行中为渐变主色（进行中额外主色光圈），未解锁节点半透明；阶段名超长省略号、`title` 悬浮可见完整信息。
- 桌面（≥768px）圆点放大到 30px，轨道 `top` 同步调整；删除已废弃的 `.plan-current` 规则。

### `sw.js`
- 缓存版本 `v9 → v10`。

## 验证（真实 DeepSeek 接口）
- 5 阶段横轴（启动 / 打基础 / 推进 / 优化 / 验收固化），节点圆心 x 依次 72 / 305 / 538 / 772 / 1005，等距排列。
- 初始：第1节点 `is-current`，进度条填充 0%。
- 勾完第1阶段 3 个任务：第1节点 `is-done`、第2节点 `is-current`，填充 25%（1/4 段），刷新后保持。
- 手机 390：5 节点等距（58 / 118 / 178 / 238 / 298），无横向溢出，无控制台报错。
