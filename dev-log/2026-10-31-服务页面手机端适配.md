# 2026-10-31 services.php 手机端适配

## 问题（390px 实测）
- 横向溢出：`scrollWidth 440 > clientWidth 390`，根因是「服务流程」行内写了 `grid-template-columns: repeat(4, 1fr)`，4×80px + 3×32px 间距超出容器
- 标题过大：h1 固定 64px、h2 32px（`--font-5xl/3xl` 不随屏幕变化）
- 四个服务区块行内固定 `1fr 1fr`，手机上两栏各 139px，正文挤成窄条
- 小程序 / AI 两块的图文顺序依赖行内 `order`，单栏时需要顺序一致

## 改动（`services.php`）
1. 新增 `$pageStyles`（`ob_start()` → `header.php` 注入），用媒体查询覆盖行内样式（行内优先级高，故用 `!important`）
2. 加类名挂钩：
   - hero `section` → `.svc-hero`
   - 4 个服务行 → `.svc-row`（含最后一个无 `margin-bottom` 的）
   - 流程网格 → `.svc-steps`，4 个圆形序号 → `.svc-step-num`
   - CTA → `.svc-cta`

### 断点
| 宽度 | 行为 |
| --- | --- |
| > 1024 | 保持原样：两栏图文交替、流程四栏、h1 64px |
| ≤ 1024 | 流程改两栏（`.svc-steps` 2 列），图文仍两栏 |
| ≤ 900 | 服务行单栏（`1fr`）、`order: 0` 统一「文字→图片」、图片 `16:10` 裁切 |
| ≤ 768 | hero `h1 36px`、区块 `h2 24px`、正文 16px、列表项顶部对齐、图片 16:10、流程两栏 64px 圆、手风琴 16px/更紧凑、CTA 标题 28px 且按钮满宽 |
| ≤ 480 | `h1 30px`、`h2 21px`、图片 `4:3`、流程 2×2 + 54px 圆、13px 说明、CTA 24px |

## 验证
- 320 / 360 / 390 / 414 / 480 / 600 / 768 / 1024 / 1280 / 1440 十档宽度：均无横向溢出，无元素越界
- 390：h1 30px、h2 21px、服务行单栏 342px、流程 2×2（161px 列宽）、手风琴 16px、CTA 24px
- 768：服务行单栏 720px、流程两栏 348px
- 1024：服务行两栏 456px、流程两栏 472px
- 1440：与改动前一致（两栏 664px、流程四栏 324px、h1 64px）
- 手机端页面总高 6469 → 6143px（流程改 2×2 后更紧凑）；无控制台报错

`sw.js` 为网络优先策略，且未改动公共样式文件，无需升版本。
