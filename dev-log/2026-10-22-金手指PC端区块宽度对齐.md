# 2026-10-22 金手指：PC 端顶部区块与三列方案区宽度对齐

## 问题
PC 端"我的目标"与"目标进度面板"仍是 720px 居中，下方三列（阶段目标 / 任务清单 / 奖励清单）宽 1440px，左右边缘对不上。

## 原因
`.saved-goals`、`.goal-progress`、`.goal-plan` 的 `max-width` 不一致（720 / 720 / 1440）；另外输入表单位于 `.goal-hero`（max-width 720）内部，宽度受父级约束。

## 改动（`assets/goal.css`，仅 `@media (min-width: 1024px)`）
- 新增统一宽度规则：`.saved-goals, .goal-progress, .goal-plan { max-width: 1440px; }`，三者与容器同宽、左右边缘对齐。
- 进度面板加宽后内边距改为 `var(--space-6) var(--space-8)`，避免内容贴边。
- 输入表单保持 720px 居中（在 Hero 标题下方，视觉上仍是居中的搜索框），不做拉伸。

## 验证（视口 1440）
- 我的目标 / 进度面板 / 三列方案区：左边缘均 24px、右边缘均 1416px（宽 1392）。
- 三列卡片等宽 451px。
- 视口 1280：三者 24 → 1256 对齐；1680：120 → 1560 对齐；390：24 → 366 对齐（单列）。
- 无横向溢出，无控制台报错。

## 备注
- `sw.js` 缓存版本 `v8 → v9`。
