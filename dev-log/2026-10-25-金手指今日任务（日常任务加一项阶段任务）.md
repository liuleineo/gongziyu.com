# 2026-10-25 金手指：去掉阶段目标与任务面板，「每日日常任务」升级为「今日任务」

## 需求
1. 去掉「阶段目标与任务」面板（不再逐阶段罗列全部任务）。
2. 「每日日常任务」改名「今日任务」，内容为：**日常任务 + 一项阶段任务**。

## 结果结构
方案区只剩一张卡：

```
今日任务   [日常任务每天 0 点重置，另含一项当前阶段任务]
  0/5 日常已完成        每天 0 点自动重置
  ▓▓░░░░░░░░（今日进度条）
  ☑ 晨起空腹称重并记录
  ☐ 阅读30页并记录页码
  ☐ 记录三餐饮食 …
  ───────────────────
  阶段推进  第1阶段·启动
  ☐ 设定每日阅读时间和书籍清单      ← 只显示当前阶段待办里的 1 项
```

- 日常任务：按天记录、0 点重置，不计入总进度。
- 阶段任务：取 `nextTask()`（当前阶段第一个未完成的任务），完成后自动换成下一条；计入总进度、完成阶段弹大奖励。
- 阶段详情仍可通过进度面板上的横轴节点点击展开（看该阶段全部内容/任务）。

## 改动

### `goal.php`
- 删除「阶段目标与任务」整个 `<section>`（含 `#stageTasks`）。
- 「每日日常任务」卡改为「今日任务」：`id="todayCard"` / `#todaySummary` / `#todayList`，新增阶段任务区：
```html
<div class="today-stage" id="todayStage" hidden>
  <div class="task-stage-title">阶段推进<span class="today-stage-name" id="todayStageName"></span></div>
  <div id="todayStageList"></div>
</div>
```

### `assets/goal.js`
- 删除 `renderStageTasks()`；`renderDaily()` → `renderToday(plan, rec)`：一次渲染日常任务 + `nextTask()` 得到的那一项阶段任务；卡片在没有日常任务且没有阶段任务时隐藏。
- 调用点全部改为 `renderToday()`：`renderAll()`、`finishTask()`、`toggleDailyTask()`、「清空进度」。
- 事件：`#todayList` → `toggleDailyTask()`；新增 `#todayStageList` → `toggleTask()`；删掉原 `#stageTasks` 的两个监听（含阶段标题点击）。
- `updateProgress()` 删掉已无对应 DOM 的各阶段计数（`gc-{i}`）更新。
- 元素引用：`el.stageTasks/dailyCard/dailySummary/dailyList` → `el.todayCard/todaySummary/todayList/todayStage/todayStageName/todayStageList`。
- 汇总文案改为「x/y 日常已完成」。

### `assets/goal.css`
- 新增 `.today-stage`（上分隔虚线 + 上间距）、`.today-stage-name`；删除已失效的 `.stage-block` 与 `.goal-node-head` 规则。

### `sw.js`
- 缓存版本 `v20 → v21`。
