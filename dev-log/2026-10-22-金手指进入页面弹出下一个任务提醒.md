# 2026-10-22 金手指：进入页面弹窗提示下一个待完成任务

## 需求
每次进入目标页面，弹窗提示接下来要完成的任务，底部两个按钮：稍后安排 / 已完成。

## 改动

### `goal.php`
页面末尾新增弹窗结构（默认 `hidden`）：
```html
<div class="goal-modal" id="taskReminder" hidden>
  <div class="goal-modal-mask" id="remindMask"></div>
  <div class="goal-modal-card" role="dialog" aria-modal="true">
    <span class="goal-modal-kicker">接下来要完成</span>
    <p class="goal-modal-stage" id="remindStage"></p>
    <h3 class="goal-modal-title" id="remindTitle"></h3>
    <p class="goal-modal-desc" id="remindDesc" hidden></p>
    <div class="goal-modal-meta" id="remindMeta"></div>
    <div class="goal-modal-actions">
      <button id="remindLater">稍后安排</button>
      <button id="remindDone" class="primary">已完成</button>
    </div>
  </div>
</div>
```

### `assets/goal.js`
- 抽出公共函数 `stageStats(plan, done)`：返回每阶段完成百分比、`finished`、当前阶段下标（全部完成为 `-1`），`updateProgress()` 改为复用它，消除重复计算。
- 新增 `nextTask()`：取「当前阶段」里第一个未完成的任务（保证按阶段顺序推进）；全部完成返回 `null`（不弹窗）。
- 新增 `openReminder()` / `closeReminder()` / `showReminder()` / `completeReminderTask()`：
  - 弹窗内容：阶段名 · 阶段目标、任务标题、任务说明、标签（预计耗时 / 优先级 / 第N/M 阶段）；
  - 「已完成」：写入 `rec.done` → 保存 → 重渲染任务与进度 → 自动弹出下一个待办（无则关闭）；
  - 「稍后安排」/ 点遮罩 / 按 ESC：仅关闭弹窗。
- `renderAll()` 末尾调用 `showReminder()`，因此进入页面、切换目标、重新拆解后都会弹出。
- 打开时给 `body` 加 `is-modal-open` 锁滚动，关闭时移除。

### `assets/goal.css`
- 新增 `.goal-modal*`：固定遮罩 + 居中卡片（最大 420px）、弹入动画、kicker 渐变标签、优先级标签配色（高=红 / 中=橙 / 低=灰）、按钮移动端纵向占满、≥768px 改为横向平分。
- `body.is-modal-open { overflow: hidden; }`。

### `sw.js`
- 缓存版本 `v10 → v11`。

## 验证（真实 DeepSeek 接口 + Playwright）
- 进入页面即弹窗（`open: true`，`body.is-modal-open`），显示"第1阶段·启动 · 完成身体基线测量并连续14天记录饮食与体重"及首个任务。
- 点「已完成」：勾选数 1 → 总进度 6%，弹窗自动切到下一个任务；再点一次：勾选数 2 → 12%。
- 点「稍后安排」：弹窗关闭、滚动锁解除、进度不变。
- 刷新：弹窗重新弹出且显示下一个待办，已完成的 2 项与 12% 进度保留。
- 点击遮罩关闭正常；手机 390：卡片 350px、两个按钮纵向各 300px、无横向溢出、无报错。
