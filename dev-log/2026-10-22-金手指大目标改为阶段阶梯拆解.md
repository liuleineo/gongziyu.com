# 2026-10-22 金手指：大目标改为「阶段阶梯」拆解

## 需求
大目标要按阶段阶梯拆目标：把最终目标切成逐级递进的阶段，前一阶段完成才进入下一阶段。

## 改动

### `api/goal.php`
- 系统提示词改为阶段拆解：开场就要求"任何大目标都要拆成一条阶段阶梯，4-6 个逐级递进的阶段，前一阶段完成才能进入下一阶段（启动 → 打基础 → 推进 → 优化 → 验收固化）"。
- `goals` 每条新增 `stage` 字段（"第N阶段·阶段名"），要求 N 严格递增、阶段间必须递进（后一阶段成果建立在前一阶段之上，不允许平行罗列）。
- `goal_normalize_plan()`：`goals` 保留并回填 `stage`，缺失时按序号补"第N阶段"；兜底目标也带 `stage`。

### `goal.php`
- 进度卡新增 `<p class="plan-current" id="planStage">` 显示"当前阶段：第N阶段·阶段名"。
- 卡片标题"目标阶梯"改为"阶段阶梯"；任务清单副标题加"按阶段推进，完成上一阶段再进入下一阶段"。

### `assets/goal.js`
- `renderGoals()`：渲染阶段徽章 `stage` + 状态徽章 `#g-state-i`（已完成 / 进行中 / 待解锁）。
- `updateProgress()`：新增阶段状态计算——先算每个阶段的完成数与是否全完成，再顺序判定：
  全完成 → `已完成`；前一阶段全完成且本阶段未完成 → `进行中`；否则 → `待解锁`；
  节点分别加 `is-done` / `is-current` / `is-locked` / `is-last` 类，并把"当前阶段"写入 `#planStage`（全部完成显示"全部阶段已完成，目标达成！"）。
- `renderTasks()`：分组标题由"目标N · 标题"改为"第N阶段·阶段名 · 标题"。
- 离线示例方案的 4 条 goals 补上阶段名（明确目标 / 备齐条件 / 持续推进 / 验收固化）。

### `assets/goal.css`
- 阶段阶梯视觉：节点之间新增竖向连接线（`::after`，已完成的阶段连线渐变高亮），`is-current` 主色描边+阴影，`is-locked` 半透明，阶段徽章/状态徽章按状态换色，序号圆圈未解锁为灰、进行中与已完成为渐变主色。
- 新增 `.plan-current`（移动端居中、桌面左对齐）、`.plan-card-note`（卡片副标题小字）。

### `sw.js`
- 缓存版本 `v6 → v7`。
