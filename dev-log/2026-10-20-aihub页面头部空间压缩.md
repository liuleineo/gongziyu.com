# 2026-10-20 aihub.php 页面头部空间压缩

## 需求
`aihub.php` 的页面头部（`.page-header`）垂直占位过大，需要压缩。

## 改动
文件：`aihub.php`（仅在该页的 `$pageStyles` 中覆盖，不影响 `tools.php` / `about.php` 等其他页面）

新增样式：
- `.page-header`：`padding: 160px 0 var(--space-16)` → `padding: 96px 0 var(--space-8)`
- `.page-title`：`font-size: var(--font-5xl)`(64px) → `var(--font-3xl)`(32px)，`margin-bottom: var(--space-4)` → `var(--space-2)`
- `.page-subtitle`：`var(--font-xl)`(20px) → `var(--font-lg)`(18px)
- `.page-header + .section`：顶部内边距 80px → 32px
- 移动端（`max-width: 768px`）进一步压缩：padding `88px 0 var(--space-6)`，标题 `var(--font-2xl)`，副标题 `var(--font-base)`，下一段顶部 `var(--space-6)`

## 效果
桌面端头部区域总高度约减少 144px，移动端约减少 160px。

## 备注
页面专属样式注入位置在 `assets/styles.css` 之后（`includes/header.php` 第 80-82 行），同优先级覆盖生效，无需 `!important`。
