# 2026-10-24 金手指：新增「每日日常任务」

## 需求
很多目标的执行其实由每天重复的日常动作构成（记录、运动、复盘…），单独拆出一块「每日日常任务」。

## 设计
- 与一次性任务彻底分开：`daily` 是每天重复执行的动作，**按天记录完成状态，0 点自动重置**，且**不计入总进度百分比与任务总数**（不会污染阶段解锁逻辑）。
- 完成日常任务同样给小奖励；当天全部完成时文案变为"今日日常任务全部完成，可以安心收工了。"

## 改动

### `api/goal.php`
- 系统提示词新增 `daily` 字段与硬约束：`daily 3-6 条`，必须是从目标里抽出的"每天重复执行的动作"，简短可重复、当天能完成，不允许一次性任务（原第 5/6 条顺延为 6/7）。
- `goal_normalize_plan()` 新增 `daily` 解析（title/desc/estimate，最多 8 条），并加入返回结构。

### `goal.php`
方案区最前面新增一张卡（无日常任务时自动隐藏）：
```html
<section class="plan-card" id="dailyCard" hidden>
  <h3>每日日常任务<span class="plan-card-note">每天重复执行，0 点自动重置</span></h3>
  <div class="daily-summary" id="dailySummary"></div>
  <div id="dailyList"></div>
</section>
```

### `assets/goal.js`
- `todayKey()`：本地日期 `YYYY-MM-DD`（不用 UTC，避免跨时区提前/延后重置）。
- `ensurePlan()`：`plan.daily` 兜底并分配 `d0/d1…` id；`record.daily = { date, ids }`，日期不是今天就自动清空 `ids`（换天重置）。
- `renderDaily(plan, rec)`：顶部「x/y 今日已完成 + 每天 0 点自动重置」与今日进度条；列表复用 `.task-item` 样式（勾选框 + 标题 + 说明 + 预计耗时）。
- `toggleDailyTask(id, checked)`：勾选写 `rec.daily.ids`，保存并重渲染；勾选时调 `grantRewards({ plan, newStages: [] }, note)` 发小奖励。
- `grantRewards(res, note)` 新增 `note` 参数，用于自定义小奖励说明。
- `buildOfflinePlan()` 补 3 条通用日常任务（记录数据 / 推进一个关键动作 / 今日复盘）。
- `renderAll()` 调用 `renderDaily()`；新增 `el.dailyCard / dailySummary / dailyList` 与 `#dailyList` 的 change 事件。

### `assets/goal.css`
- 新增 `.daily-summary / .daily-head / .daily-count / .daily-hint / .daily-bar`（渐变进度条 6px）。

### `sw.js`
- 缓存版本 `v16 → v17`。

## 验证（真实接口，目标「每天读书30页并减脂5斤」）
- 接口返回 5 条日常任务：睡前读30页 / 晨起称重 / 饮食打卡 / 走够步数 / 睡前复盘3行。
- 初始：卡片显示「0/5 今日已完成 · 每天 0 点自动重置」，进度环 0%、任务总数 15（日常不计入）。
- 勾 1 条 → 弹小奖励，计数 1/5；勾满 5 条 → 100%、提示"今日日常全部完成"、奖励文案"今日日常任务全部完成，可以安心收工了。"
- 刷新：保持 5/5（同一天）。
- 把存储里的 `daily.date` 改成昨天再刷新 → 自动重置为 0/5，进度环仍为 0%。
- PC 1440：三张卡同排（每日日常任务 / 阶段目标 / 任务清单，各 451px，y 均 947）；手机 390：三卡单列 342px，无横向溢出、无报错。
