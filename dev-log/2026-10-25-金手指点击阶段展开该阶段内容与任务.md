# 2026-10-25 金手指：点击阶段，在下方展开该阶段内容与任务

## 需求
`#planStage`（阶段横轴）那里：点击某个阶段，在下面显示该阶段的内容和任务。

## 设计
- 横轴每个阶段节点可点（也可键盘 Enter/空格），点击后在进度面板下方展开一块「阶段详情」：阶段徽章 + 状态 + 百分比 + 阶段目标 + 说明 / 衡量标准 / 节点 + 阶段进度条 + 该阶段任务列表（可直接勾选）。
- 整合面板里点击阶段标题（`.goal-node-head`）同样展开，并滚动到详情位置。
- 再次点击已展开的阶段 → 收起；详情右上「收起」按钮也可关闭。
- 进入页面默认展开**当前阶段**；进度变化时详情自动同步刷新。

## 改动

### `goal.php`
横轴后新增容器：`<div class="stage-detail" id="stageDetail" hidden></div>`

### `assets/goal.js`
- `renderStageAxis()`：节点加 `data-index`、`role="button"`、`tabindex="0"`。
- 新增 `renderStageDetail(index)`：不传 index 时取 `stageStats().currentIndex`；渲染阶段信息 + 该阶段任务（复用 `taskItemHtml()`），并 `hidden = false`。
- 新增 `selectStage(index)`（同一阶段再点即收起）、`closeStageDetail()`、`highlightStageNode(index)`（横轴节点 `is-active` 高亮）。
- 新增 `activeStage` 变量；`renderAll()` 里在 `renderStageAxis()` 后调用 `renderStageDetail()`；`updateProgress()` 末尾在详情展开时调 `renderStageDetail(activeStage)` 保持同步。
- 任务勾选抽成 `toggleTask(id, checked)`，整合面板与阶段详情共用（完成即发奖励）。
- 事件：横轴 click / keydown、整合面板 `.goal-node-head` click、详情内 checkbox change、详情「收起」click。
- 新增 `el.stageDetail` 引用。

### `assets/goal.css`
- `.stage-node` 加 `cursor: pointer`；`.stage-node.is-active` 圆点加光圈、名称主色加粗。
- 新增 `.stage-detail`（描边卡片）、`.stage-detail-head`、`.stage-detail-close`，详情内任务项底色 `--bg-primary`。
- `.goal-node-head { cursor: pointer; }`。

### `sw.js`
- 缓存版本 `v19 → v20`。

## 验证（真实接口，「每天读书30页并减脂5斤」5 阶段）
- 进入页面：默认展开第1阶段（进行中 / 0% / 0/4 / 4 个任务），横轴第1节点高亮。
- 点第3个节点 → 切到「第3阶段·推进 待解锁 0% 0/3」，高亮跟随；再点一次 → 收起，高亮清除。
- 点整合面板第2个阶段标题 → 展开「第2阶段·打基础 待解锁 0/4」并滚动到详情。
- 在详情里勾 1 个任务 → 计数 0/4 → 1/4、阶段进度 25%、弹小奖励；收起按钮可关闭。
- 手机 390：详情宽 300px，无横向溢出，无控制台报错。
