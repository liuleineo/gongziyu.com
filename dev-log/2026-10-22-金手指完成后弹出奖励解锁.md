# 2026-10-22 金手指：稍后安排关闭 / 已完成且达成条件时弹出奖励

## 需求
- 点击「稍后安排」= 关闭弹窗（不改动进度）
- 点击「已完成」时，如果本次完成使进度跨过某个奖励的解锁条件，弹出奖励内容

## 改动

### `goal.php`
新增奖励解锁弹窗（默认 `hidden`，位于任务提醒弹窗之前）：
```html
<div class="goal-modal reward-modal" id="rewardUnlock" hidden>
  <div class="goal-modal-mask" id="rewardMask"></div>
  <div class="goal-modal-card" role="dialog" aria-modal="true">
    <span class="goal-modal-kicker">奖励已解锁</span>
    <span class="reward-modal-icon"><svg .../></span>   <!-- 礼物图标 -->
    <p class="goal-modal-stage" id="rewardCond"></p>     <!-- 解锁条件 -->
    <h3 class="goal-modal-title" id="rewardTitle"></h3>
    <p class="goal-modal-desc" id="rewardDesc" hidden></p>
    <div class="goal-modal-actions">
      <button id="rewardOk" class="primary">收下奖励</button>
    </div>
  </div>
</div>
```

### `assets/goal.js`
- 新增 `planProgress(rec, plan)`：总进度百分比（与进度环同一口径）。
- `completeReminderTask()` 改造：记录完成前进度 `before` → 勾选并保存 → 计算 `after` → 重渲染任务与进度 → 关闭任务弹窗 → 收集 `before < unlockAt <= after` 的奖励放进 `rewardQueue` → `showRewardQueue()`。
- `showRewardQueue()`：队列还有奖励就展示下一条（标题 / 解锁条件 / 说明），队列空则关闭奖励弹窗并 `advanceReminder()` 弹出下一个待办；一次跨过多个奖励时会依次弹出。
- 「收下奖励」/ 点遮罩 / ESC 都走 `showRewardQueue()`；ESC 优先处理奖励弹窗，其次才是任务弹窗。
- 「稍后安排」仍只调用 `closeReminder()`（不改任何进度）。

### `assets/goal.css`
- 新增 `.reward-modal` 样式：卡片描边与投影改橙色调、`kicker` 用橙红渐变、56px 圆形礼物图标（橙底）。
- **修复隐藏失效**：本页元素用了 `display: flex/grid`，作者样式会覆盖浏览器默认的 `[hidden] { display: none }`，导致加了 `hidden` 的弹窗/区块仍然可见（点不到下面的按钮）。在文件顶部补 `[hidden] { display: none !important; }` 兜底，修复弹窗关闭后仍留在屏幕上的问题。

### `sw.js`
- 缓存版本 `v11 → v12`。

## 验证（假接口：10 个任务、奖励解锁点 20% / 40% / 100%）
- 完成第 1 个（10%）：不弹奖励，直接弹出下一个待办。
- 完成第 2 个（20%）：弹出奖励「一杯咖啡 / 解锁条件：完成前2个任务」，任务弹窗关闭，奖励清单中 1 项解锁、统计"已解锁奖励 = 1"。
- 点「收下奖励」→ 继续弹出下一个待办（任务3）。
- 完成第 3 个（30%）：不弹奖励。
- 完成第 4 个（40%）：弹出第二个奖励「看一场电影 / 解锁条件：进度40%」，已解锁 2 项。
- 「稍后安排」：两个弹窗都关闭、进度保持 40%、已解锁 2 项不变。
- 无控制台报错；`hidden` 修复后 Playwright 能正确判定元素不可见（此前关闭后仍可见）。
