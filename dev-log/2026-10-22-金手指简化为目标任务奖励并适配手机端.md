# 2026-10-22 金手指简化为「目标 + 任务 + 奖励」并适配手机端

## 需求
简化金手指系统：去掉"资源"，把"短期目标 / 长期目标"整合为一份目标阶梯，只保留 **目标 + 任务 + 奖励**，界面适配手机端。

## 数据结构变更（前后端统一）
旧：`resources` / `longTermGoals` / `shortTermGoals` / `tasks(shortTermIndex)` / `risks` / `advice`
新：
```json
{
  "restatedGoal": "", "summary": "", "duration": "",
  "goals":  [{"title","desc","measure","deadline"}],          // 整合后的目标阶梯
  "tasks":  [{"title","desc","estimate","goalIndex","priority"}],
  "rewards":[{"title","condition","desc","unlockAt"}]          // unlockAt 为 0-100 整数百分比
}
```

## 改动
### `api/goal.php`
- 系统提示词改为新 schema（goals 3-6 条 / tasks 12-24 条 / rewards 3-5 条，unlockAt 按进度递增），去掉 resources、risks、advice 要求。
- `goal_normalize_plan()` 重写：只输出 `goals / tasks / rewards`；兼容旧字段（`goals` 缺失时按"短期在前、长期在后"合并 `shortTermGoals` + `longTermGoals`，`goalIndex` 缺失时回退读 `shortTermIndex`）；`goalIndex` 越界收敛、`unlockAt` 收敛到 0-100、奖励按解锁进度排序；任务为空时按目标阶梯生成占位任务。

### `goal.php`
- 表单精简：去掉"补充信息"输入；示例目标改为横向可滚动 chips。
- 方案区改为单列三张卡：**目标阶梯 / 任务清单 / 奖励清单**；统计项第 4 格由"执行方式"改为"已解锁奖励"。

### `assets/goal.js`
- 重写渲染：`renderGoals`（带进度条）、`renderTasks`（按 `goalIndex` 分组，组头显示"目标N · 标题"与 已完成/总数）、`renderRewards`（按总进度与 `unlockAt` 比较，解锁后高亮 + 状态变"已解锁"）。
- 去掉资源/风险/建议渲染；离线示例方案同步改为 4 目标 + 12 任务 + 4 奖励（25/50/75/100）。
- localStorage key 升到 `gongziyu_goal_v2`，载入时自动清理旧结构记录（无 `plan.goals` 的丢弃）。

### `assets/goal.css`
- 全面重写为移动端优先：默认单列、按钮全宽、chips 横向滚动、进度头竖排、统计 2×2；`@media (min-width: 768px)` 再展开为桌面布局（左右分栏进度头、统计 4 列、按钮右对齐）。
- 任务项 `min-height: 44px` 保证点击热区；新增 `.reward-*` 样式（未解锁虚线灰态 / 解锁后主色高亮）。

### `sw.js`
- 缓存版本 `v5 → v6`（goal.css / goal.js 内容已变）。
