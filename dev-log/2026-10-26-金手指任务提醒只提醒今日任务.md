# 2026-10-26 金手指：任务提醒弹窗只提醒今日要完成的任务

## 需求
任务提醒弹窗以前弹的是「方案里下一个未完成的一次性任务」，会一路推到很后面的阶段。现在只提醒**今日任务**：未完成的日常任务 + 一项阶段任务。

## 规则
- 提醒队列 = 今天还没勾的日常任务（按方案顺序） + 当前阶段的 1 个待办（放在最后）。
- 阶段任务**每天只提醒一项**：当天推进过（`rec.daily.stageDone = true`）就不再弹。
- 今日任务全部完成后不再弹窗，播报 `恭喜宿主，今日任务已全部完成，明天继续。`
- 换天重置（日常 ids 与 `stageDone` 一起清空）后，第二天重新从第一个日常任务开始提醒。

## 改动

### `goal.php`
- 提醒弹窗的 kicker 加 id：`#remindKicker`（日常任务时显示「今日日常任务」，阶段任务时「接下来要完成」）。

### `assets/goal.js`
- 新增 `todayPending()`：返回今日待办数组，元素带 `kind`（`daily` / `stage`），阶段任务仅在 `!rec.daily.stageDone` 时加入。
- `openReminder(data)` 按 `kind` 区分展示：
  - daily：kicker「今日日常任务」、说明行「今日任务 · 每天 0 点重置」、标签「每日重复」+ 耗时
  - stage：保持原样（阶段名 · 阶段目标、优先级、第 N/M 阶段）
  - 存 `data-task-id` 之外再存 `data-task-kind`
- `showReminder()` / `advanceReminder()` 改用 `todayPending()[0]`；队列空时播报「今日任务已全部完成」。
- `completeReminderTask()` 按 kind 分发：daily → `toggleDailyTask(id, true)`（按天记录 + 小奖励）；stage → `finishTask()` + `grantRewards()`。
- `ensurePlan()`：新一天的 `record.daily` 增加 `stageDone: false`；`finishTask()` 完成时置 `stageDone = true`（手动勾选也算当天已推进）。

## 验证（真实接口，「每天读书30页并减脂5斤」5 条日常 + 5 阶段）
- 弹窗顺序：日常 1 → 日常 2 → 日常 3 → 日常 4 → 日常 5 → 阶段任务「选定3本待读书目…」
- 完成阶段任务后不再弹窗，播报「恭喜宿主，今日任务已全部完成，明天继续。」；总进度 6%（阶段任务计入）。
- 刷新页面：不再弹窗（当日已推进过），今日任务卡仍显示下一条阶段任务，可继续手动推进。
- 把存储日期改成昨天后刷新：日常回到 0/5，提醒重新从「每日阅读30页」开始。
- 无控制台报错。

`sw.js` 缓存版本 `v21 → v22`。
