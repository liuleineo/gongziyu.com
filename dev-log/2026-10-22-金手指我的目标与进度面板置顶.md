# 2026-10-22 金手指：我的目标 + 目标进度面板置顶

## 需求
拆解目标后，"我的目标"与目标进度面板放在页面最上方。

## 改动

### `goal.php`
- 把「我的目标（多目标切换）」`#savedGoals` 与「目标进度面板」从方案区内部移到页面顶部（Hero 之后、输入表单之前）。
- 进度面板包在新增的 `<div class="goal-progress" id="goalProgress" hidden>` 里，与 `#goalPlan`（阶段目标 / 任务清单 / 奖励清单）解耦。
- 新的页面顺序：Hero → 我的目标 → 目标进度面板 → 输入表单 → 提示/骨架屏 → 阶段目标 → 任务清单 → 奖励清单。

### `assets/goal.js`
- 新增 `el.progressWrap = $('goalProgress')`。
- `renderAll()` 同时显示 `#goalProgress` 与 `#goalPlan`。
- `showSkeleton(state)` 同步显隐两个区域（`state || !current()`），避免失败后残留空卡片。
- 删除最后一个目标时同时隐藏 `#goalProgress` 与 `#goalPlan`。

### `assets/goal.css`
- 新增 `.goal-progress { max-width: 720px; margin: 0 auto var(--space-6); }`，并让其中的 `.plan-progress-card` 去掉下外边距避免重复间距。
